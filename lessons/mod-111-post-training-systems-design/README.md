# mod-111-post-training-systems-design: Post-Training Systems Design

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 14 hours

## Learning objectives

- Walk a problem from product goal to a base-model + dataset-budget + objective-stack proposal
- Allocate dataset budget across SFT, DPO, RLHF, and safety tuning with documented trade-offs
- Design eval gates, release-candidate selection, adapter registry, and rollback strategy
- Make the build-vs-buy / fine-tune-vs-RAG / fine-tune-vs-prompt-engineering decision defensibly
- Author a model card and release review that satisfies governance / risk / security partners

## Structure

- `01-…md` … `0N-…md`: lecture chapters.
- `exercises/`: per-exercise prompts.
- `labs/`: long-form hands-on labs.
- `quizzes/`: knowledge checks.
- `resources.md`: external references.
