# mod-110-managed-fine-tuning-apis: Managed Fine-Tuning APIs

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 9 hours

## Learning objectives

- Run a managed fine-tuning job on OpenAI (and at least one of Anthropic, Gemini, Mistral, Cohere, Bedrock, Azure AI Foundry)
- Convert an SFT dataset between Hugging Face and managed-API JSONL formats correctly
- Reason about cost, data residency, IP, and privacy implications of managed vs. self-hosted fine-tuning
- Decide between fine-tuning a closed-weight frontier model and fine-tuning an open base model
- Hand off eval to the same eval harness used for self-hosted adapters so comparisons are fair
